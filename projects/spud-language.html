Spud

A simple, biological programming language.

Spud is a simple language with the goal of becoming a self-hosted low-level, multi-use language capable of creating many different types of programs.


You can view the source code and its examples inside of this repo.

  • Argumentive functions return values: `pot`, `bloom`
